
# 🎓 Student Performance Analysis

## 📌 Project Overview

The **Student Performance Analysis** project focuses on cleaning and analyzing student performance data to understand their overall academic performance.

The project includes **data cleaning, missing value handling, null value treatment, removal of irrelevant values, and performance classification**.

At the end of the analysis, students are categorized into **Good, Average, and Poor** performance levels and the results are represented using **bar graphs** for easy understanding.

## 🎯 Objectives

* Identify missing values in the dataset.
* Handle null values appropriately.
* Detect and remove irrelevant or unnecessary data.
* Clean the dataset before performing analysis.
* Analyze student performance.
* Categorize students into **Good, Average, and Poor** performance groups.
* Visualize the final results using bar graphs.

## 📊 Performance Classification

The cleaned student data is analyzed and students are grouped into three performance categories:

* 🟢 **Good** – Students with higher performance
* 🟡 **Average** – Students with moderate performance
* 🔴 **Poor** – Students with lower performance

The final classification is displayed using **bar graphs**, making it easier to compare the number of students in each performance category.
